# invisible because the draugr `replace` wiped the scar/wound genes that fought it in the same pre_skin_color
# stage). Textures are vanilla and gender-neutral (gfx/models/portraits/decals/visual_traits/), so female = male.
# The variant is chosen per wight by a wight_v* character flag (see wight_trait_modifiers.txt), set once at
# conversion. NOTE: decal priorities / alpha are a first pass — tune in-game against the draugr skin.

# Reports from Ereska, KngZawd and CinkoSenpai: living characters -- women above all -- rendering with the wound layer.
# Some of them on NEW games, which rules out the save-drift story on its own.
#
# Every applier this mod owns sets these genes to EXACTLY 1.0 (wight_trait_modifiers.txt), so the whole
# 0.0-0.85 span was never ours to use -- and yet the old curves reached FULL STRENGTH at 0.5, and the skin
# tint at 0.2. Anything that put a stray mid-range value in this gene's slot -- another mod's gene churn
# shifting indices, a portrait cache from a different playset, an accessory pack rewriting the pool -- got a
# fully rendered corpse for it. So the curves are now flat zero until 0.85 and only reach full at 1.0:
# our own look is bit-identical, and every value we did not deliberately write renders NOTHING.
# This is the belt to the by-name trigger gate's braces (see wight_trait_modifiers.txt); either one alone
# should stop it, and neither costs anything when the mod is behaving.
#
